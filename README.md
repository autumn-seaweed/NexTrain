# ネクストレイン（NexTrain）
### 検索せず、次の電車をひと目で。

**NexTrain**は、よく使う駅の発車時刻をホーム画面・ロック画面のウィジェットに表示する、シンプルな乗車アプリです。検索なしで、毎日の「次の電車まであと何分か」をいちばん速く知ることに特化しています。

![Banner Image](images/banner.png)
## 🚀 特徴 (Features)

- ホーム画面ウィジェット（小・中サイズ）
- ロック画面ウィジェット（横長・インライン・サークル）
- 発車時刻、あと何分か、両数を表示（遅延情報が提供されている場合は遅れも表示）
- 「行き」「帰り」をワンタップで切り替え
- 時間帯で表示を自動切り替え（例：平日の昼までは「行き」、以降は「帰り」、週末は「行き」）

_**注：公共交通オープンデータ（ODPT）を元に開発しているため、JR系などは未対応です。オープンデータが拡大され次第、対応路線を拡大致します。**_
